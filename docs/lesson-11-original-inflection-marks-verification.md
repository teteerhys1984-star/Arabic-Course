## تدقيق المادة والمسار التعليمي

- جُردت أقسام النص: المدخل والأهداف، تعريف الإعراب، العلامات الأربع، أمثلة الضمة/الفتحة/الكسرة/السكون، المقارنة، منهج الإعراب، التدريب ٨ أسئلة، الختامي ١٠ أسئلة، الواجب بأجزائه الثلاثة، والخلاصة ومعاينة الدرس ١٢ التعليمية. اختبارات المحتوى والعرض تتحقق من وجود الأمثلة المعروضة فعلًا، وترتيب الخيارات، وتفرّد الجواب لكل سؤال، وإعراب كل كلمة في «قرأَ الطالبُ القصةَ في المكتبةِ» و«كتبَ الطالبُ الدرسَ في الدفترِ».
- جرى ضبط الرفع بالضمة، والنصب بالفتحة، والجر بالكسرة **للاسم**، والجزم بالسكون **للمضارع الصحيح الآخر** في الأمثلة؛ فُصلت علامة الإعراب عن الحركة الظاهرة/حركة البناء، فلم تُسمّ فتحة «قرأَ/كتبَ» نصبًا ولا تنوين «مجتهدٌ» علامة رفع مستقلة. شُرحت «لن/أنْ/كي» و«لم/لا» الناهية، وخبر كان دون توسع، وأُرجئت أحكام المعتل والعلامات الفرعية.
- أُنشئت ٢٠ مسألة منصة مستقلة بصياغات وسياقات مغايرة لمجموع أسئلة المصدر الثمانية والعشرة؛ أربع صفحات × خمسة. تعليلاتها التفصيلية في `SolutionsArea` بعد التسليم. تُظهر أسئلة التدريب والختامي مفاتيحها وتعليلاتها فقط بعد زر التحقق؛ وتظل مفاتيح الاختبار المستقل ودرجاته وحلوله محجوبة إلى أن تُفحص الصفحات الأربع ويُضغط زر التسليم. تحفظ الإجابات بين الخطوات، وتُلغى النتيجة والحلول عند تعديل الإجابة أو إعادة الضبط.
- الكلمات التي لم تظهر مميزة بخط عريض في النص المرسل حُددت في واجهة الواجب بوضوح: «الطالبُ، القصةَ، الحديقةِ، يهملْ، يشرحُ». معاينة الموضوعات المذكورة للدرس ١٢ بقيت نصًا توضيحيًا فقط؛ موضعها في تسلسل المنهج الحالي يحتاج مراجعة تحريرية بشرية كما يسجل تقرير التدقيق.

## نتائج الفحوص المحلية الفعلية

| الفحص | النتيجة |
| --- | --- |
| `npm ci` | نجح؛ أُزيلت اعتماديات Chromium/Playwright المؤقتة المستعملة للفحص البصري ولم يتغير `package-lock.json`. |
| `npm run validate` | نجح كاملًا: lint، RTL، architecture، test-ux، فحوص الدروس/الصرف/الإملاء/الإعراب، ثم **٦٩ ملف اختبار و٨٠٠/٨٠٠ اختبار**، ثم TypeScript وVite build. |
| `npm run test -- --maxWorkers=2 --testTimeout=20000` | نجح: **٦٩/٦٩ ملفًا، ٨٠٠/٨٠٠ اختبار**، بما فيها **١٦/١٦** تخص ملفات الدرس ١١. استعملت المهلة الأطول لهذا التشغيل فقط؛ لم تتغير إعدادات الاختبارات في المستودع. |
| `npm run build` | نجح (`tsc -b && vite build`). يظهر تحذير Vite غير حاجب عن chunk يزيد ٥٠٠ kB؛ لم يُعد تنظيم حزم المنصة خارج نطاق الدرس. |
| `npm run check:rtl`، `check:architecture`، `check:test-ux`، `check:parsing`، `check:morphology-source` | نجحت جميعها مستقلةً أيضًا، مع ضمان عدد الدروس وصرفها دون إضعاف الفحوص السابقة. |
| `git diff --check` و`git diff --cached --check` قبل الالتزام | نجحا دون أخطاء فراغات أو تعارضات. روجع diff للملفات الستة عشر: ١٦١١ سطرًا مضافًا و١٥ سطرًا محذوفًا، وكل تعديل خارج ملفات الدرس مقتصر على التسجيل/التوقعات والفحوص اللازمة. |

**محاولة إعادة تشغيل موثقة:** نجح `npm run validate` أولًا مع الاختبارات الافتراضية (٨٠٠/٨٠٠)، لكن تشغيلًا مستقلًا للـ٨٠٠ اختبار مع `--maxWorkers=4` تعثّر في ١٣ اختبارًا عبر ٧ ملفات، أغلبها بسبب مهلة الخمس ثوانٍ أثناء الضغط وبعض آثار تباطؤ التفاعل. أُعيدت المجموعة نفسها دون تعديل الكود مع عاملين ومهلة ٢٠ ثانية، فنجحت ٨٠٠/٨٠٠. لا يُعرض التعثر المؤقت بوصفه نجاحًا، ولا أخفيه وراء نجاح الإعادة.

## الفحص البصري والتفاعل في متصفح فعلي

- شُغّلت معاينة Vite واستُخدم **Chromium عبر Playwright فعلًا** على أبعاد ٣٢٠×٨٤٤، ٣٩٠×٨٤٤، و١٤٤٠×٩٠٠ بكسل. بعد إعادة تحميل الدرس لكل بُعد، نُقّلت **الخطوات الأربع والعشرون** وفُحصت عناصر الخطوة وحدود `documentElement.scrollWidth`؛ لم يظهر تمرير أفقي (`scrollWidth = innerWidth`) أو خطأ JavaScript. روجعت صور حقيقية للمقدمة على سطح المكتب ولجداول الإعراب/التدريب على الهاتف؛ حُذفت اللقطات التجريبية من المستودع بعد الفحص لتجنّب إضافة أصول غير مطلوبة.
- كشف الفحص الهاتفي الأول انضغاط عنوان جدول الإعراب وخروج ملخص تصحيح التدريب من العرض. أُصلح الأمران في CSS الخاص بالدرس فقط، ثم أكد فحص المتصفح إعادة ظهور العنوان والملخص داخل شاشة ٣٩٠ بكسل؛ وحُفظت الاحترازات في `responsive.test.ts`.
- نُفذ الاختبار المستقل بالنقر الحقيقي على هاتف بعرض ٣٩٠ بكسل: ٥ أسئلة في كل من الصفحات الأربع؛ زر التسليم معطّل قبل فحصها، ولا تغذية راجعة أو حلول بعد فحص صفحة أو الأربع قبل التسليم. بعد التسليم ظهرت **٢٠/٢٠** وجميع الحلول العشرين؛ عند تغيير إجابة أُغلقت الحلول والنتيجة، ثم أعطت إعادة التحقق/التسليم **١٩/٢٠**؛ أعادت «إعادة ضبط الاختبار» قفل التسليم. لم تقع أخطاء JavaScript أو تجاوزات أفقية أثناء هذه التجربة.
- قيد للمشهد المصوّر: ظهرت زخرفة موجودة أصلًا في رأس المنصة ببدائل محارف في Chromium المعزول (قد يكون ذلك مرتبطًا بخط ويب غير متاح هنا)؛ النص العربي والحركات والجداول المقروءة لم تتأثر. لم نغيّر تنسيق المنصة العام خارج النطاق. انتهت مهلة طلب screenshot إضافي **بعد تنقلات كثيرة في الصفحة نفسها**، لكن نجحت لقطة جديدة للمقدمة على سطح المكتب بعد فتح متصفح نظيف؛ اكتمل فحص الأبعاد والتفاعل مباشرة من DOM دون الادعاء بوجود لقطات لكل شاشة.
