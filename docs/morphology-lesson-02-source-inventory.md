# الصرف — الدرس الثاني: الميزان الصرفي — جرد المصدر وتوزيع الخطوات

جردٌ لكل نقطة من نقاط المادة المعتمدة (`docs/source/morphology-lesson-02.md`) وموضعها من خطوات
الدرس الأربع والثلاثين، مع بيان ما أُضيف من المنصة في كل خطوة. لا تُحذف نقطة من المصدر ولا
تُعرض خارج موضعها؛ والتصحيحات موثّقة بأرقامها في
[`morphology-lesson-02-audit.md`](./morphology-lesson-02-audit.md).

## ما أُضيف من المنصة في كل خطوة (لا يُنسب إلى المصدر)

| الخطوة | الإضافة |
|---|---|
| ١ | بطاقات وصفية للدرس، وطريقة دراسته (نص الدرس + القاعدة الذهبية في مقدمته) |
| ٢ | جدول ربط الأهداف الثمانية بأقسام الاختبار |
| ٤ | مختبر المقابلة (اختيار كلمة → جدول مقابلة حروفها) |
| ٦ | معنى «أَكْتَبَ» الموثّق (غ-1) |
| ٨ | مختبر «علّم الحروف الأصلية» (٦ كلمات) + بطاقة تصحيح خ-2 |
| ٩ | توضيحا ش-5 وغ-2 وش-4 + بطاقة تصحيح خ-3 |
| ١١ | ثلاثية حَسَبَ/حَسِبَ/حَسُبَ بمعانيها وتوثيقها (خ-4) + نشاط الأوزان الستة |
| ١٢ | توضيح غ-4 + مختبر الرباعي (٦ كلمات) |
| ١٣–١٤ | نشاط «حاول ثم اكشف التحليل» بدل العرض الساكن + توضيح غ-3 |
| ١٥ | جدول عدد الحروف مقابل عدد الأصول (غ-5) + توضيح ش-6 + مختبر أسماء (٦ كلمات) |
| ١٦ | توضيحا ش-1 وش-2 + مختبر الشدة + نشاط فَعَّلَ/فَعْلَلَ (٥ كلمات) |
| ١٧ | نشاط الهمزة (أصلية/زائدة، ٤ كلمات) + توضيح ش-7 |
| ١٩ | جدول أوزان المعتلة (ف-3) + نشاط ربط الألف بأصلها (٤ كلمات) + توضيح ش-9 |
| ٢١–٢٥ | تحويل التدريبات الخمسة إلى أنشطة تفاعلية بمفاتيح المصدر نفسها، مع جداول المقابلة |
| ٢٦ | بطاقة المراجعة السريعة (١٠ مصطلحات) + عرض توزيع الدرجات |
| ٢٧–٣٠ | صياغة الأسئلة في مخطط المنصة (`TestDefinition`)، ومفاتيح مفصلة (ف-2)، وأوصاف الصفحات ودرجاتها |
| ٣١ | حساب الدرجات الثلاثين وتفصيلها، وقاعدة «أول خمس كلمات» (م-2، م-3) |
| ٣٣ | قائمة ما تركه الدرس للدرس الثالث (بلا تبويب فارغ ولا درس غير مبني) |
| ٣٤ | أقسام ح–ك: توزيع الدرجات ومعيار التقييم وملاحظات المعلم وبطاقة المراجعة وسجل التصحيحات |
