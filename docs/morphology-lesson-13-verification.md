# تقرير تحقق الدرس ١٣: صِيَغُ المبالغة

## النطاق والبنية
- المعرّف `morphology-lesson-13` مسجّل مرة واحدة في `sectionId: morphology` بالرقم ١٣.
- معرف `lesson-13` في قسم الأساسيات والنحو مستقل كما هو، ولم يُنشأ درس إملاء ثالث عشر.
- الدرس يستخدم تدفق `LessonFlow` المتتابع والروابط الموجودة للدرس/القسم، ومنطقة المعلم تستورد بوابة `TeacherSpace` وكلمة المرور المشتركة دون نسخها.
- عدد أجزاء التدفق بعد اكتماله ١٩ خطوة: ٩ خطوات تعليم/تدريب، أربع صفحات اختبار، خطوة التسليم، خطوة التصحيح، الواجب، الملخص، منطقة المعلم، وخاتمة العودة للقسم.
- لا يُنشأ اختبار وحدة للصرف ولا اختبار Vitest خاص بالدرس. أضيف فحص تحقق موجّه بالسكريبت، وسُجّل تعريف الاختبار في فحص المطابقة المشترك الموجود أصلًا.

## تحقق المحتوى والاختبار
- خمس محطات للأوزان؛ ستة أمثلة تحليل جمل؛ خمسة أمثلة اشتقاق؛ ثلاثة أخطاء شائعة.
- تدريب مستقل: ٨ أسئلة، تقدم ٠/٨، تفسير بعد الاختيار، وإعادة تدريب؛ لا يضاف إلى درجة الاختبار.
- الاختبار النهائي: ١٢ سؤالًا موزعة ٤ + ٤ + ١ (الجدول ذو ٣ درجات) + ٣ (سؤال الجملتين بدرجتين وسؤالا الفرق بدرجة لكل منهما)، ومجموع الدرجات ١٥ = ٤ + ٤ + ٣ + ٤. أسئلة الجدول والجمل والفرق تُراجع يدويًا، ويعرض المحرك عدد درجاتها المعلّقة بدل ادعاء تصحيح آلي.
- صفحة الاختبار تخفي الصحة والحلول إلى ما بعد تسليم كل الصفحات؛ التحقق الصفحي قبل التسليم لا يعرض الحلول. مفاتيح المعلم داخل `SolutionsArea` في `TeacherSpace`.
- التشكيل والعرض العربي معزولان بـ`bdi`, `dir=rtl`, `lang=ar` وCSS خاص بالدرس. جداول الشاشات الضيقة تسمح بالتمرير الأفقي للحفاظ على عناوين الأعمدة.

## سجل أوامر التحقق

### التهيئة والمحاولات السابقة
- نُفّذ `npm ci` بنجاح لتثبيت الاعتماديات المحددة في القفل. أبلغ npm عن ثغرة واحدة عالية الخطورة في شجرة الاعتماديات؛ لم يُنفّذ `npm audit fix` لأنه خارج نطاق الدرس.
- أخفق الفحص الساكن للدرس أولًا بسبب اختلاف ضبط التشكيل بين النص والفحص؛ عُدّل الفحص ليتحقق من النص المعتمد فعليًا.
- تعذّر `npm run lint` و`npm run build` قبل تثبيت الاعتماديات لغياب `eslint` و`tsc`؛ أُعيد تشغيلهما بعد التثبيت ونجحا.
- أظهرت الجولة الأولى من `npm run validate` اختبارات تكامل قديمة ما زالت تفترض أن الصرف يتوقف عند ١٢ درسًا، كما احتوى ختام الدرس ١٢ على رسالة قديمة تقول إن الدرس ١٣ غير موجود. حُدّثت توقعات التسجيل/التوجيه فقط لتقبل الدرس ١٣ وترفض درسًا رابع عشر، وصُحّح رابط الدرس التالي في ختام الدرس ١٢. أُبقيت اختبارات المصدر السابقة والحراس فعّالة.
- يتطلب الاختبار النهائي الموزون دعمًا مشتركًا لدرجات الأسئلة. لذلك سُجلت البصمات الجديدة، لهذه الملفات المشتركة الثلاثة فقط، في جرد البصمات المحمي: `TestPageView.tsx` و`grading.ts` و`types.ts`. لم تُستثنَ هذه الملفات من الحارس؛ بقي الحارس يقارن بصماتها، كما بقيت بصمات بقية الملفات السابقة دون تعديل.

### النتيجة النهائية
- `npm run validate`: **نجح بالكامل**؛ شمل lint، فحوص RTL والهندسة المعمارية وتجربة الاختبار، جميع فحوص الدروس والصرف/الإملاء والمصدر، الاختبارات، وبناء الإنتاج.
- الاختبارات: **٨٧ ملفًا ناجحًا، ٩٩٣ اختبارًا ناجحًا، دون إخفاقات**.
- `npm run check:lesson12` و`npm run check:lesson13`: **نجحا** مع بقاء تحقق المصدر والنطاق والحلول المحمية.
- `npm run check:morphology-lesson-13`: **نجح**؛ ١٣ تسجيلًا لقسم الصرف، ١٩ خطوة تدفق، ٨ أسئلة تدريب، و١٢ سؤال اختبار موزونًا إلى ١٥ درجة (٤ + ٤ + ٣ + ٤)، دون اختبار وحدة للصرف.
- `npm run check:morphology-source`: **نجح**؛ ٥٧٦ سطرًا/خلية جوهرية و٣٩ عنوانًا تمت مطابقتها.
- `npm run lint`، و`npm run check:rtl`، و`npm run check:architecture`: **نجحت** ضمن التحقق الشامل.
- `npm run build`: **نجح**. ظهر تحذير حجم الحزمة الرئيسية (نحو ٣٫٧ ميغابايت قبل الضغط، أكبر من حد ٥٠٠ كيلوبايت) وتحذيرات React `act(...)` قديمة في اختبار الدرس السابع؛ لم تمنع أيٌّ منها نجاح الاختبارات أو البناء.
- فحص الحزم ما زال يبلغ عن ثغرة عالية واحدة؛ لم يُنفّذ إصلاح شامل للحزم.
- فحص بصري يدوي في متصفح حقيقي: **لم يُجرَ**؛ لا يُدّعى هنا إجراء مراجعة بصرية.
