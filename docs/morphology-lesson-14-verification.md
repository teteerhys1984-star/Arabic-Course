# تقرير التحقق — الصرف، الدرس الرابع عشر: اسم التفضيل

## البنية والتسجيل

- المعرّف: `morphology-lesson-14`، القسم `morphology` فقط، الرقم ١٤؛ يأتي بعد `morphology-lesson-13`.
- المسار المباشر: `#/lesson/morphology-lesson-14`؛ يفتح الدرس من بطاقته ومن عنوان المسار المباشر.
- تظهر في قسم الصرف ١٤ بطاقة مرتبة، من دون تغيير ترتيب الدروس ١–١٣. يبقى `basics-lesson-14` مستقلًا، ولا يوجد `spelling-lesson-14`.
- الدرس القادم المذكور فقط: «اسم الزمان واسم المكان» (الدرس الخامس عشر). لم يسجل درس خامس عشر.
- التدفق يستخدم `LessonFlow` المشترك بالاتجاه `rtl`، و25 خطوة فعلية ضمن 12 مجموعة موضوعية. يتضمن ذلك ٩ خطوات شرح تمهيدي/تعليمي، ٤ خطوات تدريب، ٥ صفحات اختبار، ثم التسليم والتصحيح والواجب والخريطة والخلاصة ومنطقة المعلم والدرس القادم والختام.
- لا تتجاوز واجهة `LessonFlow` خطوة واحدة معروضة في الوقت نفسه؛ المحتوى المقسم في الخطوات والجداول يمرر أفقيًا عند ضيق الشاشة.

## تغطية المادة والتفاعل

- جداول: ٨ أفعال وأوزانها؛ ٧ شروط مع تفسير وأمثلة؛ ٥ صيغ «أكثر/أشد + المصدر»؛ أربع حالات اسم التفضيل؛ مقارنة المشتقات؛ وثلاثة أمثلة للتحليل الصرفي والإعراب؛ يتضمن الاختبار سؤالًا تحليليًا إنشائيًا لتحديد المفضّل/المفضّل عليه وإعراب «أسرع».
- التدريبات: ٤ مجموعات × ٥ فقرات = ٢٠ سؤالًا. الأنواع: استخراج، إكمال، تحويل، وتصحيح/تمييز العبارة الصحيحة. التصحيح عبر `TestPageView` و`useTestEngine`؛ تظهر التغذية التفسيرية بعد المحاولة/التحقق، وتبطل نتيجة الصفحة عند تعديلها؛ إعادة التدريب تمسح الإجابات.
- الاختبار المستقل: ٢٠ فقرة/٢٠ درجة، الصفحات بالترتيب `[٥، ٤، ٤، ٣، ٤]` أي ٥ + ٤ + ٤ + ٣ + ٤.
  - الاختيار ٥ درجات: آلي.
  - الاستخراج ٤: آلي مع إجابات مقبولة محددة.
  - الإكمال ٤: آلي مع البدائل الموثقة.
  - التحويل ٣: إنشائي/مراجعة بشرية.
  - التحليل ٤: ثلاثة عناصر محددة آليًا، وعنصر إعرابي إنشائي يدوي.
  - الدرجة الآلية القصوى ١٦؛ توجد ٤ درجات مراجعة يدوية. لا تُعرض هذه الدرجات على أنها مصححة آليًا.
- الحلول الطلابية لا تظهر عند فحص الصفحة؛ يجب فحص الصفحات الخمس، ثم التسليم، ثم الضغط على زر عرض الحلول. تعديل الإجابات يبطل التسليم والكشف. مفاتيح التدريب والواجب والاختبار في `TeacherSpace` و`SolutionsArea` المشتركين.
- الواجب يحوي أنشطته الخمسة كاملة. توجد معايير تقييم ونماذج إرشادية للمعلم، لا إجابات طالب مفروضة.
- تمت إضافة اختبارات محتوى، ومسار/تفاعل، واستجابة RTL. تشمل فحوص المسار عدد الخطوات والمجموعات والتدريبات والاختبار، وفتح بطاقة القسم والرابط المباشر، والكشف بعد التسليم، والإبطال عند التعديل، وإعادة المحاولة.

## الفحوص المنفذة

الفحوص التالية نُفذت فعليًا على النسخة النهائية:

| الأمر | النتيجة |
|---|---|
| `npm ci` | نجاح؛ تم التثبيت. أبلغ npm عن ١٨ ثغرة في شجرة الاعتماديات (١٤ متوسطة و٤ عالية)، ولم يُنفذ إصلاح واسع خارج النطاق. |
| `npx tsc -b` | نجاح ضمن `npm run validate`. |
| `npm run lint` | نجاح ضمن `npm run validate`. |
| `npx vitest run --reporter=dot` | نجاح: ٩٦ ملف اختبار، ١٠٦٤ اختبارًا. وشمل `npm run validate` كذلك `npm run test` (Vitest). |
| `npm run validate` | نجاح كامل؛ شمل lint، RTL، architecture، فحوص المحتوى، Vitest، والبناء. |
| `npm run build` | نجاح ضمن `npm run validate`. |
| فحوص الصرف ١، ٢، ١٣، ١٤ والمصدر | نجاح ضمن `npm run validate`. |
